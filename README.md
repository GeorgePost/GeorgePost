# 💫 About Me

Computer Engineering student at the University of Waterloo, transferred from York CS (3.9 GPA). I spent the last two summers building internal business tools at Bothwell-Accurate — React SPFX dashboards, data migrations, API integrations — and I keep personal projects going to learn things that don't come up at work.

- 🚀 **Currently building:** [DistanceTracker.API](https://github.com/GeorgePost/DistanceTracker.API) — a REST API in ASP.NET Core for logging multi-stop trip distances, with Stripe subscriptions, Redis caching, and JWT auth
- 🏆 **Won** the MLH ElevenLabs prize track at Hack Canada with [Dubbify](https://devpost.com/software/dubbify) — an AI agent that joins live phone calls and translates speech in real time
- 🔨 **Other projects:** a SQL schema visualizer (Hack the 6ix), a LiDAR navigation aid for visually impaired users (Bear Hacks), and a school scheduling tool I actually deployed
